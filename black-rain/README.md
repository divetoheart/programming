# BLACK RAIN

A short, browser-playable sci-fi FPS prototype. Deploy from this folder as a static website.

## Features

- Hand-modeled procedural 3D dropship, assault rifle, hostile arachnids, and swamp environment (no external 3D models)
- Introductory dropship deployment sequence
- Heavy rifle combat with limb damage, green splatter, recoil, and particles
- Dynamic rain, lightning, murky fog, and swamp scenery
- Desktop and touch controls

## Run

Serve this directory with any static file server or open `index.html` locally in a WebGL2-capable browser. For Vercel set project root to `black-rain`, framework `Other`, with no build command.

## Controls

Desktop: WASD to move, mouse to aim, click to shoot, R to reload. Mobile: joystick, drag-to-look, FIRE button. Landscape recommended.
