# Mournreach Canon Runtime

**READ `READ_FIRST.json` before broad retrieval.**

Stable canon/policy lives here. Mutable campaign state lives on the `campaign-data` branch.

- `READ_FIRST.json`: minimum-load context and authority order.
- `presentation.json`: chat-first visual narration format.
- `npc-simulation.json`: full NPC sheets, XP, memory, alignment, decisions, off-screen progression.
- `gm/campaign-spine.json`: hidden authored spine with mandatory reveals/convergences and fail-forward routes. Never surface undiscovered GM-only content during play.
- `assets.json`: canonical art identity, persistent Library paths, first-relevance generation/reuse policy, and generic pools.

Narration is never authoritative over these files or the live save.
