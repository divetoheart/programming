# Jaydon's Game Lab

A small browser-game starter that runs with plain HTML, CSS, and JavaScript.

## Play locally

Open `index.html` in a browser.

For a local development server, run this inside the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy on Vercel

Import the `divetoheart/programming` repository and set the project's **Root Directory** to:

```text
jaydon-game
```

No build command or framework preset is required for this starter.

## Where to edit

- `index.html` — title and page structure
- `style.css` — colors and layout
- `game.js` — game rules, movement, enemies, scoring, and visuals

## Easy first changes

1. Rename **Star Runner**.
2. Change the player and enemy colors in `game.js`.
3. Adjust `player.speed`.
4. Replace circles with images or sprites.
5. Add levels, lives, sounds, or a start menu.
